# JobBubble Bugs & Issues

This repository's GitHub Issues section is the central place to review JobBubble bugs.

## In-app bug reports

Reports submitted from **Help & Support → Report a bug** are created as GitHub Issues with a title beginning with:

`[Bug Report]`

They include the user's description plus the JobBubble app version, Android version, device model, report screen, and submission time. The Android app never contains a GitHub access token; issue creation is handled by the JobBubble backend.

## Labels

- `bug` — a software problem that needs investigation or correction.
- `user-report` — a report submitted from the JobBubble app.

## Review workflow

1. Open the repository's **Issues** tab.
2. Filter for open issues with `label:bug` or search for `[Bug Report]`.
3. Comment on the issue with investigation notes when useful.
4. Close the issue after the fix is verified.

Do not put passwords, API keys, access tokens, or other secrets into issue comments or reports.
